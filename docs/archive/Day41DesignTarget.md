# Day41 Design Target

The next confirmed design target is a full-viewport Solo gameplay presentation:

- Solo gameplay fills the entire viewport.
- The floating/resizable player-facing puzzle window is replaced.
- Hub HUD and the 3D world are fully covered or hidden while playing.
- Stage transformations affect the full background, panels, board, existing blocks, tray pieces, text accents, particles, and eventually audio.
- Existing placed blocks update when a stage changes.
- Return Hub restores the normal hub presentation.

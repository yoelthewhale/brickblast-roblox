# Project Tracker

Task tracking moved to **GitHub Issues** and the **BrickBlast Development** project board. This file is intentionally short — it's a pointer, not a duplicate tracker, so there's only one place to check for what's actually in progress.

- **Issues**: https://github.com/yoelthewhale/brickblast-roblox/issues
- **Project board**: https://github.com/users/yoelthewhale/projects/1/views/1

## Labels

Every issue is tagged with:

- `type: *` — bug, feature, polish, documentation, testing, or technical-debt
- `area: *` — which system it touches (gameplay, ui, achievements, audio, mobile, infrastructure, world, etc.)
- `priority: *` — critical, high, medium, or low
- `future` — intentionally not scheduled yet
- `needs-design` — blocked on a design decision before it's buildable

## Reporting a bug or requesting a feature

Use the issue templates in `.github/ISSUE_TEMPLATE/` (`bug_report.md`, `feature_request.md`, `studio_playtest_report.md`) so new issues carry the same structure as existing ones.

# Block Blast Battle UI Mockup Specs

## B1 - Blocky Competitive

### Color Palette
- `navy`: `#101827`
- `charcoal`: `#182235`
- `blue`: `#1EA7FF`
- `blueDeep`: `#0D5EEB`
- `gold`: `#F5B83E`
- `green`: `#36D96A`
- `danger`: `#F04E66`
- `text`: `#F7FBFF`

- Font choices: GothamBlack for titles, GothamBold for buttons/stats, Gotham for body.
- Corner radii: 10-14 px cards; 18 px primary action; small pills for stats.
- Stroke widths: 2-4 px crisp dark outlines with electric-blue selected strokes.
- Shadow treatment: Offset charcoal shadows at 28-36% opacity, no soft muddy glow.
- Standard spacing scale: 8 / 12 / 16 / 24 / 32 px scale.
- Button treatment: Chunky rectangular buttons, beveled top highlight, compressed pressed state.
- Panel treatment: Navy/charcoal layered panels with gold reward chips and blue action rails.
- Icon style: White chunky silhouettes in navy tiles, one perspective, heavy readable shapes.
- Desktop and mobile behavior: Desktop keeps nav on the left and match panel on right; mobile collapses to bottom dock plus top resources.
- Benefits: Most competitive and readable, preserves a lot of gameplay visibility.
- Tradeoffs: Less playful than arcade and needs careful art direction so it does not feel too serious.

## B2 - Polished Arcade

### Color Palette
- `ink`: `#172039`
- `sky`: `#1EBBFF`
- `cyan`: `#6EF4FF`
- `lime`: `#7BED4B`
- `pink`: `#FF5DC8`
- `gold`: `#FFD247`
- `orange`: `#FF8B3D`
- `text`: `#FFFFFF`

- Font choices: GothamBlack for playful headers, GothamBold for buttons, Gotham for helper text.
- Corner radii: 14-20 px buttons; 16 px cards; circular icon badges.
- Stroke widths: 3 px dark structural strokes; 2 px inner bright highlight strokes.
- Shadow treatment: Layered hard arcade shadows plus subtle white top highlights.
- Standard spacing scale: 10 / 14 / 18 / 28 / 36 px scale.
- Button treatment: Dimensional puzzle-color buttons with clear selected, hover, locked, and disabled states.
- Panel treatment: Bright blue shop/play cards inside dark frame; rewards separate from nav.
- Icon style: Chunky toy-like silhouettes, simple fill shapes, no tiny details.
- Desktop and mobile behavior: Desktop uses left island nav and right shop panel; mobile turns nav into thumb-safe bottom tabs.
- Benefits: Strongest Block Blast identity and most front-page-friendly energy.
- Tradeoffs: More visual weight; must be tuned so it does not crowd smaller screens.

## B3 - Clean Block Tech

### Color Palette
- `glass`: `#07111F`
- `panel`: `#111A2C`
- `line`: `#3847FF`
- `violet`: `#8E5CFF`
- `cyan`: `#31D7FF`
- `gold`: `#E7C15B`
- `success`: `#28E08F`
- `text`: `#F4F8FF`

- Font choices: GothamBold/GothamMedium feeling for tight labels, GothamBlack only for key headings.
- Corner radii: 8-12 px compact cards; 999 px small status pills.
- Stroke widths: 1-2 px translucent blue/purple strokes; selected state adds a bright left rail.
- Shadow treatment: Soft glass shadows, low opacity, minimal glow.
- Standard spacing scale: 6 / 10 / 14 / 20 / 28 px scale.
- Button treatment: Compact translucent controls, clear keyboard/gamepad focus rings, minimal hover lift.
- Panel treatment: Dark glass panels with geometric separators and small reward chips.
- Icon style: Solid geometric block symbols, white/cyan, compact and monochrome-friendly.
- Desktop and mobile behavior: Desktop HUD hugs edges; mobile shows only top stats, bottom quick actions, and one focused sheet.
- Benefits: Best gameplay visibility and premium feel.
- Tradeoffs: Less playful and may need stronger block identity elsewhere in the map/art.
